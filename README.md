# JSON Log Viewer

Beautiful structured log viewer for debugging. Automatically transforms JSON logs into readable, interactive output with syntax highlighting, filtering, and search.

## Quick Start

1. Install the extension
2. Start debugging (F5)
3. View formatted logs in the **JSON Log Viewer** panel

## Configuration

Access via VSCode Settings → "JSON Log Viewer":

- Toggle automatic formatting
- Collapse JSON by default
- Auto-scroll to latest logs
- Theme: light, dark, or auto
